# 단시간근로자 연차계산기

단시간근로자의 주 소정근로시간과 통상근로자의 연차유급휴가 일수를 입력해 연차유급휴가 시간을 계산하는 정적 웹 계산기입니다. HTML 파일 하나로 동작하며 별도의 서버나 패키지 설치가 필요하지 않습니다.

## 실행하기

1. [`outputs/annual_leave_calculator.html`](outputs/annual_leave_calculator.html) 파일을 내려받습니다.
2. 파일을 웹 브라우저에서 엽니다.
3. 통상근로자 연차일수와 두 근로자의 주 소정근로시간을 입력하고 **연차휴가시간 계산하기**를 누릅니다.

계산기는 기본값으로 통상근로자 연차 15일, 단시간근로자 주 20시간, 통상근로자 주 40시간을 사용합니다. 별도 입력 없이 열어도 기본값의 계산 결과를 보여줍니다.

## 계산 기준

```text
통상근로자 연차휴가일수 × (단시간근로자 주 소정근로시간 ÷ 통상근로자 주 소정근로시간) × 8시간
```

계산 결과에 1시간 미만의 단수가 있으면 법령 기준에 따라 1시간으로 올림합니다. 입력한 단시간근로자의 주 소정근로시간이 15시간 미만이면 연차 규정 적용 여부를 확인하라는 안내를 표시합니다. 주별 근로시간이 다른 경우에는 4주 평균으로 판단해야 합니다.

## GitHub Pages 등에 배포하기

이 프로젝트는 빌드 과정이 필요 없는 정적 페이지입니다. 저장소를 GitHub에 올린 뒤 GitHub Pages의 배포 대상으로 HTML 파일을 지정하면 공개 주소를 만들 수 있습니다. 공개 주소를 네이버 블로그 글에 링크로 넣으면 방문자가 별도 페이지에서 계산기를 사용할 수 있습니다. 네이버 블로그 게시물 본문에 HTML과 JavaScript를 직접 삽입해 작동시키는 방식은 지원되지 않을 수 있습니다.

## 법령 참고

- [근로기준법 시행령 제9조 및 별표 2](https://www.law.go.kr/법령/근로기준법시행령): 단시간근로자의 연차유급휴가 시간 산정 방식 및 1시간 미만 처리 기준
- [근로기준법 제18조](https://www.law.go.kr/법령/근로기준법): 단시간근로자의 근로조건 적용 기준

## 유의사항

이 도구는 입력된 연차일수와 소정근로시간을 바탕으로 시간 환산을 돕습니다. 실제 연차 발생 여부와 일수는 근속기간, 출근율, 사업장 적용 요건 및 근로계약 등 개별 사정에 따라 달라질 수 있으므로 별도로 확인하세요.
